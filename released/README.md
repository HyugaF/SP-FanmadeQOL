# Stronghold Protocol: Alliance — Release Bundle

## Berkas Rilis (Release Bundles)

Berkas paket rilis lengkap siap pakai (termasuk kode sumber, dependensi `node_modules`, seluruh aset visual/audio, serta tekstur papan 3D resmi):

- **Bundle ZIP**: `released/Stronghold-Protocol-v0.1.2-bundle.zip`
- **Tautan Unduh Langsung**: Kunjungi `/download.html` pada browser untuk mengunduh langsung dari server aplikasi.

### Cara Menjalankan (Quick Start)

1. **Install Node.js 22 atau 24 (LTS)**:
   - **Windows**: Jalankan `winget install OpenJS.NodeJS.LTS` di PowerShell atau unduh installer dari https://nodejs.org/en/download
   - **macOS**: `brew install node@22` atau unduh dari website resmi.
   - **Linux**: Gunakan package manager distro Anda, `nvm`, atau `fnm`.

2. **Ekstrak ZIP**:
   - Ekstrak berkas `Stronghold-Protocol-v0.1.2-bundle.zip` ke direktori dengan path pendek (misal: `C:\Games\Stronghold-Protocol`).

3. **Mulai Server / Mainkan**:
   - **Windows**: Klik dua kali `scripts\start-windows.bat`.
   - **macOS / Linux**: Jalankan `./scripts/start.sh` (atau `bash scripts/start.sh`).

4. **Buka Game**:
   - Browser akan otomatis membuka `http://localhost:3000`.
   - Bagikan alamat IP LAN yang tampil di terminal kepada teman di jaringan yang sama untuk bermain bersama (co-op 1–4 pemain).
